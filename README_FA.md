# پوشش ایران | نبض ایران
**شعار:** بدون حمایت سیاسی از شخصی

قالب اولیهٔ یک سایت خبری دوزبانه (فارسی/انگلیسی)، واکنش‌گرا، با تم روشن/تیره، رنگ قرمز، جست‌وجو، دسته‌بندی، زمان انتشار و پیوند منبع.

## چه چیزهایی آماده است؟
- صفحهٔ اصلی موبایل‌پسند، فارسی/انگلیسی و تم روشن/تیره
- نمایش تازه‌ترین خبرها به ترتیب زمان
- جست‌وجو و فیلتر دسته‌بندی
- زمان UTC، نام منبع و پیوند مستقیم
- گردآوری اطلاعات عمومی RSS با حذف موارد تکراری
- GitHub Actions با زمان‌بندی هر ۱۰ دقیقه (بهترین تلاش؛ اجرای زمان‌بندی ممکن است با تأخیر انجام شود)

## محدودیت مهم
این نسخه یک **نمونهٔ اولیه** است، نه خبرگزاری کاملاً راستی‌آزمایی‌شده. برچسب «نیازمند راستی‌آزمایی مستقل» عمداً روی خبرها قرار دارد. RSS به‌تنهایی تأیید صحت نیست؛ برای خبرهای مربوط به سرکوب، تلفات، عملیات نظامی و ادعاهای طرف‌های درگیر، قبل از انتشار قطعی باید منبع دوم مستقل و زمان/مکان رویداد بررسی شود. این کد از هوش مصنوعی برای ساخت ادعای جدید استفاده نمی‌کند و خلاصهٔ RSS را کوتاه می‌کند. ترجمهٔ دقیق فارسی/انگلیسی هنوز به سرویس ترجمه نیاز دارد؛ در این نمونه عنوان و خلاصهٔ منبع در هر دو فیلد قرار می‌گیرد، پس ممکن است زبان واقعی هر دو یکی باشد.

## راه‌اندازی رایگان با GitHub Pages
1. یک حساب GitHub بساز یا وارد شو.
2. یک مخزن جدید **Public** بساز، مثلاً `pooshe-iran-news`.
3. فایل‌های این پوشه را در ریشهٔ مخزن بارگذاری کن؛ پوشهٔ `.github/workflows` هم باید بارگذاری شود.
4. در مخزن برو به **Settings → Pages** و بخش Build and deployment را روی **GitHub Actions** بگذار.
5. در تب **Actions**، گردش‌کار `Update news and publish site` را یک بار با **Run workflow** اجرا کن.
6. بعد از موفقیت، نشانی Pages که در **Settings → Pages** نمایش داده می‌شود، سایت عمومی توست.
7. نشانی واقعی را در `robots.txt` و `sitemap.xml` جایگزین `YOUR-USERNAME` و `YOUR-REPOSITORY` کن.
8. در Google Search Console نشانی سایت را اضافه کن و sitemap را ارسال کن. ایندکس‌شدن فوری یا قطعی نیست.

## تغییر منابع
نشانی RSSها در `feeds.json` است. پیش از استفادهٔ عمومی، هر خوراک را آزمایش کن و شرایط استفاده، حق نشر و مجوز بازنشر آن را بررسی کن. از خوراک‌هایی استفاده کن که دسترسی و بازنشر فراداده/خلاصه را مجاز می‌دانند. این نسخه متن کامل مقاله‌ها را کپی نمی‌کند.

## دربارهٔ زمان‌بندی
GitHub Actions رایگان برای پروژه‌های عمومی در دسترس است، اما زمان‌بندی cron تضمین دقیق دقیقه‌ای ندارد و ممکن است تأخیر داشته باشد. اگر سایت بزرگ شد یا به اجرای تضمینی‌تر نیاز داشت، سرویس زمان‌بندی مستقل لازم است. workflow با هر اجرا JSON خبرها را به مخزن commit می‌کند؛ اگر اجراها به سقف سهمیه برسند، باید فاصلهٔ اجرا را بیشتر کرد.

## قبل از راه‌اندازی عمومی، این‌ها را اضافه کن
- ایمیل تماس و صفحهٔ اصلاح/گزارش خطا
- سیاست حریم خصوصی و شرایط استفاده
- صفحهٔ «دربارهٔ روش راستی‌آزمایی»
- فهرست منابع تأییدشده و فرایند بازبینی انسانی
- ترجمهٔ واقعی فارسی/انگلیسی
- Open Graph image و favicon اختصاصی
- آزمون اعتبار RSSها و رسیدگی به خطاهای خوراک

## منابع نمونه
خوراک‌های موجود در `feeds.json` فقط نمونه‌اند و باید پیش از انتشار بررسی شوند. اگر یک RSS از کار افتاد، آن را با خوراک معتبر و مجاز جایگزین کن.
